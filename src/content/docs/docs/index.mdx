Pleinbook is a sketchbook for quick studies, not finished pieces. Every page is one layer of wet
paint on paper, fixed to the glass, with no undo, and colours mix like real pigment. This manual
shows you around.

New to Pleinbook? Start with [Getting started](/docs/getting-started/).
